# R94 — FREE-CHAT vs WORK SEPARATION (Ross owner directive, 2026-07-17)

Applies to the four leaders: Wren, TP-Pip, Asa (Acer-Cass), Bill.

## FREE CHAT (the four-way chat pipeline)
- The four-way chat pipeline is for TALKING FREELY: passing information,
  collaborating, questions/answers, coordination, sharing references.
- On it they MAY talk freely — because they are NOT changing code and NOT
  executing tasks. It is conversation only.
- The pipeline CANNOT execute code or Task Council work (enforced: the relay is
  messaging-only; the boardroom/reception carry messages, not actions).

## WORK (governed)
- Any actual WORK — code changes, configuration, deployment, deletion, trading
  actions, gate flips, or any governed operation — MUST go through the TASK
  COUNCIL and obey the Task Council rules + ALL rulebooks (R01-R93,
  rulebook_2026-07-07.md).
- A request that arrives in free chat asking for work must be converted into a
  Task Council submission before anyone acts on it. Chat never authorizes work.

## Summary
  Talking/collaborating  -> four-way chat pipeline, talk freely (no code).
  Doing/changing anything -> Task Council + rulebooks.
